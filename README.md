VolumeForge — Калькулятор объёма тел на 7 языках
VolumeForge — это коллекция из семи независимых реализаций калькулятора объёма геометрических тел. Каждая версия работает на своём языке программирования и предлагает удобный интерфейс для быстрого расчёта объёма с расширенными возможностями.

✨ Уникальные возможности (общие для всех версий)
📐 Поддержка множества 3D-фигур:

Куб, параллелепипед, шар, цилиндр, конус

Пирамида, призма, тор, эллипсоид, усечённый конус

🎯 Интерактивный выбор фигуры с подсказками по вводу параметров

📊 Сохранение истории вычислений в JSON-файл

💾 Экспорт результатов в CSV и текстовый файл

🌍 Поддержка разных единиц измерения (см³, м³, дюймы³, литры)

🔄 Мгновенный пересчёт при изменении параметров (в веб-версиях)

🖥️ Интерфейсы:

Командная строка (CLI) с интерактивным меню

GUI (Tkinter) в Python

Веб-интерфейс в JavaScript и PHP
